# Автономная поставка Qwen3.5-0.8B

В репозитории нет весов модели. Их pinned-описание находится в
`models/qwen_qwen3.5-0.8b.manifest.json`: модель `Qwen/Qwen3.5-0.8B`, ревизия
`2fc06364715b967f1860aea9cf38778875588b17`, лицензия Apache-2.0. Манифест
ссылается на официальный model API, репозиторий и текст лицензии Hugging Face.
Размер набора по API — 1 759 750 582 байта; файл весов — 1 746 942 600 байт и
проверяется по SHA-256.

## Онлайн-установка (только по явному согласию)

```python
from qwen_offline import install_model, runtime_settings

model_dir = install_model("/path/to/models/qwen3.5-0.8b", consent=True)
settings = runtime_settings(model_dir)
```

Установка не выполняется при запуске приложения. Она проверяет свободное место,
скачивает каждый файл в staging-каталог, умеет продолжить `.part` после
обрыва, проверяет pinned-размер/хеш и только затем атомарно публикует каталог.
Незавершённая или повреждённая модель не считается установленной.

## Перенос на компьютер без сети

```python
from qwen_offline import export_bundle, import_bundle

export_bundle(model_dir, "qwen3.5-0.8b.bundle.zip", consent=True)
import_bundle("qwen3.5-0.8b.bundle.zip", "/path/to/models/qwen3.5-0.8b", consent=True)
```

Bundle проверяется на path traversal, лишние файлы, полноту набора, revision и
SHA-256 весов. Веса не следует добавлять в Git; используйте защищённое
хранилище артефактов и передавайте bundle отдельно.

После установки runtime получает `local_files_only=True` и
`allow_network_download=False`. Существующие настройки с `local_files_only`
отключённым также не разрешают скрытую загрузку: сетевой путь должен проходить
через этот установщик и явное согласие пользователя.

## Слабые компьютеры

`estimate_resources()` и `check_resources()` оценивают место на диске и пиковую
память. CPU-режим приложения использует float32 и требует ориентировочно 4 ГБ
доступной RAM; MPS/CUDA экономнее. При нехватке памяти запуск блокируется с
безопасным no-op, исходный обезличенный текст не меняется.

## Smoke-тест настоящей модели

Runtime Qwen, как и основное приложение, использует только Python 3.11.x.
Версии Torch, Torchvision и Transformers зафиксированы в
`requirements/requirements-qwen.txt`; hash-lock файлы `requirements/lock-qwen.txt`
и `requirements/lock-qwen-intel.txt` описывают отдельные окружения. В offline-
дистрибутив вместе с моделью включаются wheel-пакеты выбранного lock-файла,
совместимые с целевой ОС и архитектурой.

Обычные тесты используют fake backend и не скачивают модель. Настоящий тест
запускается только явно и только если локальный каталог уже установлен:

```bash
QWEN_MODEL_DIR=/path/to/models/qwen3.5-0.8b \
  pytest -q tests/test_qwen_real_smoke.py
```

В тест не передаются исходные значения: используется текст с тестовыми
плейсхолдерами, а проверяется сохранность токенов и отсутствие сетевого
доступа. Без `QWEN_MODEL_DIR` тест помечается skipped.

Контрольный прогон 24.08.2026 с настоящими весами и полностью локальным
`QWEN_MODEL_DIR` прошёл на Python 3.11; тест сохранил оба синтетических
плейсхолдера и не обращался к сети.
