# Релизные заметки: DOCXдодыр v3.0.2

Официальный релиз версии **3.0.2** десктопного приложения **DOCXдодыр** — локального инструмента для интеллектуального обезличивания, маскирования персональных данных (ПДн), очистки метаданных и правового анализа документов.

---

## Что нового в версии 3.0.2

### 1. Исправления и улучшения для macOS
- **Нативный диалог Finder**: исправлено открытие системного окна выбора файлов по клику на область загрузки. Устранена несовместимость символа `/` в описании фильтров файлов с регулярным выражением валидации `pywebview`. Добавлен отказоустойчивый fallback на общий диалог файлов.
- **Поддержка Drag & Drop с кириллицей на APFS**: решена проблема, при которой файлы с русскими названиями (буквы `й`, `ё` и др.) не определялись при перетаскивании из Finder из-за различий в нормализации Юникода (декомпозированная форма NFD в Cocoa/APFS против композитной NFC в WebKit).
- **Защита от записи в read-only директории (DMG-образ)**: если исходный документ находится на диске, доступном только для чтения (смонтированный образ DMG или системная защищённая папка), приложение больше не падает с `PermissionError`, а автоматически сохраняет очищенный результат в папку `~/Downloads/DOCXdodyr_Output` и логирует предупреждение.
- **Информативные сообщения об ошибках**: окно ошибки в UI теперь выводит точный и понятный текст причины сбоя (с санитизацией системных путей пользователя) вместо общего системного уведомления.
- **Валидация формата .doc**: добавлена явная подсказка для устаревших бинарных файлов Word 97–2003 с предложением пересохранить файл в современный формат `.docx`.

### 2. Кросс-платформенная стабильность и CI
- **Фоллбэк конвертации DOCX в PDF на Windows**: обеспечена гарантированная генерация PDF через встроенный PyMuPDF на системах без установленного Microsoft Office (включая Windows CI).
- **Синтетические PDF-тесты без внешних зависимостей**: исключена зависимость тестов от локальных директорий, сформирован полноценный кириллический текстовый слой в синтетических PDF.
- **Изоляция тестов POSIX-лаунчера**: исключен запуск тестов `run_macos.command` через заглушку WSL bash на платформе Windows.

### 3. Пакетная сборка
- Обновлены установщики PKG для архитектур Apple Silicon (arm64, процессоры Apple M) и Intel (x86_64).
