# Хранение и удаление данных

Версия 3.0.2. Источник путей: `app_paths.py`; фактический путь показан во встроенной справке. Переменные DOCXDODYR_DATA_DIR, DOCXDODYR_USER_DATA_DIR, DOCXDODYR_CONFIG_DIR, DOCXDODYR_CACHE_DIR и DOCXDODYR_LOG_DIR могут переопределить каталоги.

| Данные | macOS по умолчанию | Windows по умолчанию |
|---|---|---|
| Настройки, списки, очередь, vault, recovery, models | ~/Library/Application Support/DOCXdodyr | %LOCALAPPDATA%\DOCXdodyr |
| Кэш | ~/Library/Caches/DOCXdodyr | %LOCALAPPDATA%\DOCXdodyr\Cache |
| Журнал | ~/Library/Logs/DOCXdodyr | %LOCALAPPDATA%\DOCXdodyr\Logs |

`settings.json` хранит настройки, `Исключения.txt` и `Замены.txt` — пользовательские списки. Они могут содержать исходные значения. `review_queue.json` — очередь решений; `.review_context.enc` — зашифрованный контекст. Ключ vault находится в системном keyring. `recovery` хранит контрольные точки; `models` — необязательные веса Qwen. Системный каталог временных файлов и временные папки обработки также могут содержать промежуточные документы. Выходные файлы, исходники, manifests, дешифраторы и их резервные копии лежат в выбранных пользователем каталогах, а не обязательно рядом с настройками.

Срок хранения задаёт пользователь: автоматическое удаление всех данных по календарному сроку не реализовано. После сбоя не удаляйте временные файлы до проверки результата восстановления.

Для удаления: закройте приложение, решите, нужны ли сохранённые результаты и дешифраторы, затем удалите соответствующие каталоги данных, настроек, кэша и журналов через Finder или Проводник. Удалите модель кнопкой управления Qwen либо вместе с её каталогом. Отдельно проверьте папки обработанных комплектов, корзину, резервные копии и синхронизируемые облачные папки. Удаление приложения через корзину или деинсталлятор не означает удаления пользовательских данных. Ключ vault удаляйте через системное хранилище только после отказа от восстановления всех связанных контекстов. Сервис/учётную запись сверяйте с `review_context.py`, не удаляйте чужие ключи.

Удаление файлов не гарантирует физическое стирание SSD или резервных копий. Для носителей с чувствительными данными применяйте установленную в организации процедуру уничтожения.
