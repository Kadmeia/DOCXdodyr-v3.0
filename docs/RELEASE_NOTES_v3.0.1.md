# Релизные заметки: DOCXдодыр v3.0.1

Официальный релиз версии **3.0.1** десктопного приложения **DOCXдодыр** — локального инструмента для интеллектуального обезличивания, маскирования персональных данных (ПДн), очистки метаданных и правового анализа документов.

---

## Что нового в версии 3.0.1

### 1. Архитектура и безопасность (Local-First)
- **100% Local-First**: полная обработка на локальной машине без отправки файлов в сеть или внешние облачные сервисы.
- **Криптографическая защита**: шифрование контекста сессии проверки с помощью Fernet (AES-128-CBC с HMAC) и системного диспетчера ключей.
- **Очистка скрытых данных**: удаление метаданных, примечаний, скрытого текста, истории правок и полей форм.
- **Целостность дистрибутивов**: контрольные суммы релизных сборок фиксируются в `SHA256SUMS.txt`.
- **Регламент отката**: порядок действий при обнаружении критических дефектов описан в [ROLLBACK_PROCEDURE.md](ROLLBACK_PROCEDURE.md).

### 2. Интеллектуальный NER-движок и форматы плейсхолдеров
- **Интеграция с картриджем Pullenti**: глубокий синтаксический анализ текстов делопроизводства РФ.
- **Контракты плейсхолдеров**:
  - Паспортные данные разделены на независимые токены: `[СерияПаспорта]`, `[НомерПаспорта]`, `[КодПодразделения]`;
  - Поддержка реестровых номеров туроператоров: `[НомерРТО]`;
  - ФИО во всех падежах, СНИЛС, ИНН, ОГРН, адреса, банковские реквизиты (БИК, счета), контакты и судебные дела.

### 3. Мультиформатная обработка и OCR
- **DOCX, XLSX, PDF**: структурная обработка документов Office и PDF с сохранением форматирования.
- **Двойной движок OCR**:
  - **macOS**: аппаратное распознавание через нативный **Apple Vision** Framework;
  - **Windows / Fallback**: интеграция с **Tesseract** OCR для сканированных страниц.

### 4. Запуск и совместимость
- Скрипты запуска в один клик: `run_windows.bat` для Windows и `run_macos.command` для macOS.
- Инструкции по системным предупреждениям безопасности операционных систем (**SmartScreen** на Windows и **Gatekeeper** на macOS) приведены в руководстве пользователя.
- Опциональная интеграция с локальной нейросетью Qwen для контекстного анализа сложных документов.
