# Политика скрытых данных

## API

`hidden_data.inspect_hidden_data(path)` возвращает агрегированный отчёт без
исходного текста: комментарии, сноски/концевые сноски, исправления Word,
скрытый текст, встраиваемые объекты, макросы, custom XML, EXIF/XMP, PDF-
аннотации, формы, вложения и признаки цифровой подписи.

`hidden_data.sanitize_hidden_data(source, target, ...)` создаёт новую копию.
Исходный файл не изменяется. По умолчанию удаляются комментарии, исправления,
вложения, аннотации и EXIF/XMP; сноски и скрытый текст требуют явного флага:

```python
from hidden_data import sanitize_hidden_data

report = sanitize_hidden_data(
    source, target,
    remove_footnotes=False,      # видимое содержание договора
    remove_hidden_text=False,    # может быть частью шаблона
    strict=True,                 # ошибка вместо сомнительной копии
)
```

`hidden_data.flatten_pdf_to_images(source, target, dpi=150)` — необратимый
режим для PDF. На выходе остаётся только растровое изображение каждой
страницы; текстовый слой, аннотации, вложения и пользовательские метаданные
не переносятся. Рекомендуемый порядок в backend: обезличить → очистить
скрытые части → при включённом флаге `irreversible_pdf` расплющить PDF →
создать audit-сертификат.

## Безопасные ограничения

В приложении кнопка «Проверить скрытые данные» сначала вызывает инспекцию и
показывает только типы рисков и количества. Для каждой найденной части можно
выбрать «Сохранить», «Обезличить» или «Удалить». Удаление требует отдельного
подтверждения и всегда создаёт новую копию; исходник не меняется. Инспекция
возвращает одноразовый токен, привязанный к SHA-256 входного файла, поэтому
решение нельзя применить к изменившемуся или другому документу.

Для комментариев, сносок, концевых сносок и скрытого текста действие
«Обезличить» прогоняет текст через тот же Pullenti и ту же batch-сессию, что и
основной документ. Batch ID и агрегированный отчёт фиксируются в audit, но
исходные значения туда не попадают.

- При повреждённом Office XML, зашифрованном PDF или PDF с цифровой подписью
  `strict=True` поднимает `HiddenDataError`; целевой файл не создаётся.
- Подписанный Office-пакет (часть `_xmlsignatures`) также отклоняется до записи:
  сохранение подписи после изменения нельзя доказать.
- Удаление сносок отключено по умолчанию, поскольку меняет видимый смысл
  документа. Удаление скрытого текста также требует явного решения.
- Необратимый PDF нельзя восстановить в исходный текстовый документ. Оригинал
  хранится отдельно и не меняется.
- PDF `format` может содержать техническое значение версии PDF, но title,
  author, creator, producer, dates и XMP не переносятся.
- Модуль не использует Tesseract и не выполняет распознавание текста.
