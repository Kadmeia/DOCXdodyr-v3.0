## 🌟 Главные новшества и преимущества версии 2.2.0

### 1. 100% Локальная обработка и бескомпромиссная приватность (Local-First)
- **Полная изоляция от сети**: Все операции обезличивания, морфологического разбора, OCR и дешифрования производятся **строго на вашем компьютере**.
- **Network-Deny безопасность**: Интеграции с внешними облачными нейросетевыми сервисами исключены. Приложение гарантированно работает на изолированных рабочих станциях (Air-Gapped) без доступа в Интернет.
- **Защищённый дешифратор**: Файл сопоставления (`дешифратор.json`) сохраняется только локально в указанной вами папке и шифруется.

### 2. Новый стандарт разграничения паспортных данных РФ
- В соответствии с юридическими стандартами реализовано сквозное разграничение реквизитов паспорта гражданина РФ на три независимых плейсхолдера:
  - `[СерияПаспорта]` — 4 цифры серии;
  - `[НомерПаспорта]` — 6 цифр номера;
  - `[КодПодразделения]` — код вида `XXX-XXX`.
- Обеспечено 100% корректное восстановление и точное позиционирование при дешифровании.

### 3. Расширенный юридический анализ (NER) и защита от ложных срабатываний
- **Номера туроператоров и реестров**: Внедрен специализированный плейсхолдер `[НомерРТО]` для номеров в ЕФРТ (РТО, МВТ, ВНТ, МТ3) с защитой от случайных совпадений.
- **Белые списки государственных органов**: Публичные ведомства (*Департамент финансов города Москвы, Арбитражный суд, Верховный Суд, Банк России, УФК, Казначейство, Минюст, МВД, ФССП, ЗАГС*) и общероссийские классификаторы (*ОКТМО, ОКВЭД, ОКПО*) гарантированно сохраняются в открытом виде.
- **Контрагенты и подписанты**: Сохранение организационно-правовых форм (*ООО, ПАО, АО, ГАУК, ГБУ, МУП, АНО*) с маскированием наименований в кавычках (`ООО «[Наименование]»`). Должности сохраняются, ФИО во всех падежах заменяется на `[ФИО]`.
- **Адреса и даты**: Полное маскирование адресов (`[Адрес]`) и дат документов (`[Дата]`).
- **Счета и контакты**: Разделение на `[Р/с]`, `[К/с]`, `[Л/с]`, телефоны (`[Телефон]`), сайты (`[Сайт]`), почту (`[Email]`), ИНН, КПП, ОГРН, БИК.

### 4. Нативное распознавание текста со сканов (OCR)
- **macOS**: Нативное оптическое распознавание через Apple Vision Framework (высокая скорость, поддержка кириллицы, нулевые сторонние бинарники).
- **Windows**: OCR выполняется через локально установленный Tesseract; автоматическая загрузка OCR-движков отсутствует.

### 5. Кроссплатформенная нативная упаковка
- **macOS**:
  - Нативный `.app` бандл с поддержкой Apple Silicon (`arm64`) и Intel (`x86_64`).
  - Hardened Runtime, разрешения entitlements, иконка в стиле macOS Big Sur+ (`assets/DOCXdodyr.icns`).
  - Готовый сжатый дистрибутив `DOCXdodyr-2.2.0-arm64.dmg` со ссылкой на папку «Программы».
- **Windows**:
  - Сборка под Windows 10/11 64-бит (`DOCXdodyr-Setup-2.2.0-win64.exe`).
  - Установка без прав администратора (Per-User в `%LOCALAPPDATA%\Programs\DOCXdodyr`).
  - Высокая четкость интерфейса HiDPI (`PerMonitorV2`) и поддержка длинных кириллических путей документов (`UTF-8 activeCodePage`).
  - Портативный ZIP-архив `DOCXdodyr-2.2.0-win64.zip`.

### 6. Высокая надёжность и Crash Recovery
- Атомарная запись настроек и чекпоинтов обработки.
- Автоматическое обнаружение прерванных сессий после перезагрузки или сбоя питания.
- Пакетная обработка десятков документов с формированием единого сквозного дешифратора пачки.

### 7. Model Manager для локальной нейросети Qwen
- Базовый дистрибутив остаётся компактным (~18 МБ на Windows, ~270 МБ на macOS) и не содержит тяжелых весов нейросети.
- При необходимости пользователь может в один клик скачать или импортировать локальную модель Qwen 2.5 0.8B (~1.75 ГБ) для продвинутого грамматического согласования текста.

## 🚀 Инструкция по первому запуску

Поскольку DOCXдодыр распространяется как независимое бесплатное ПО (Freeware) без покупки дорогостоящих коммерческих корпоративных сертификатов Apple и Microsoft, при первом запуске операционная система может показать предупреждение подсистем безопасности (Apple Gatekeeper на macOS или Microsoft SmartScreen на Windows):

### На macOS (Apple Gatekeeper):
1. Смонтируйте скачанный `.dmg` и перетащите значок `DOCXdodyr` в папку `Программы`.
2. При первом запуске откройте `Программы` в Finder, нажмите **правой кнопкой мыши** (или удерживая Control) на `DOCXdodyr` и выберите **«Открыть»**.
3. В появившемся окне подтверждения нажмите кнопку **«Открыть»**. В дальнейшем приложение будет запускаться обычным двойным кликом.

### На Windows:
1. Запустите файл `DOCXdodyr-Setup-2.2.0-win64.exe` или распакуйте `.zip`.
2. При появлении синего окна фильтра *Windows SmartScreen* («Система Windows защитила ваш компьютер»):
   - Нажмите текстовую ссылку **«Подробнее»** (More info);
   - Нажмите появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).

## 🔍 Проверка контрольных сумм SHA-256

Для проверки подлинности и целостности скачанных файлов выполните команду в терминале:

**На macOS / Linux:**
```bash
shasum -a 256 -c SHA256SUMS.txt
```

**На Windows (PowerShell):**
```powershell
Get-FileHash .\DOCXdodyr-Setup-2.2.0-win64.exe -Algorithm SHA256
```
