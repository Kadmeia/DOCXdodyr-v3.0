# Анализ прав на распространение нейросетевых моделей и алгоритмов машинного обучения
## Проект «DOCXдодыр» (Версия 2.2)

Дата аудита: 3 сентября 2026 г.  
Статус: Завершено и согласовано с ADR 0001, ADR 0004 и ADR 0007.

---

## 1. Введение и регуляторный контекст

Приложение «DOCXдодыр» использует алгоритмы машинного обучения и лингвистического анализа для распознавания текста (OCR), извлечения именованных сущностей (NER) и грамматического согласования текста. В рамках подготовки к публичному релизу проверены лицензионные условия и ограничения на распространение всех моделей.

---

## 2. Анализ компонентов и моделей

### 2.1. Локальная LLM модель Qwen (Qwen3.5-0.8B)
- **Идентификатор**: `Qwen/Qwen3.5-0.8B`
- **Правообладатель**: Alibaba Cloud / Qwen Team
- **Лицензия**: **Apache License 2.0** (полный текст доступен в репозитории модели на Hugging Face).
- **Права на использование и распространение**: Лицензия Apache 2.0 разрешает коммерческое и некоммерческое использование, воспроизведение, модификацию и распространение весов модели при сохранении уведомлений об авторских правах и текста лицензии.
- **Архитектурное решение проекта (ADR 0007)**:
  - Веса модели (~1.75 ГБ) **НЕ включаются** в базовые дистрибутивы приложения (.app, DMG, Windows Setup .exe). Это обеспечивает легковесный размер установщиков (~150–250 МБ) и гарантирует работоспособность на компьютерах с ограниченным дисковым пространством и ОЗУ.
  - Поставка модели реализована через **Model Manager**: опциональная загрузка по прямому согласию пользователя (`consent=True`) с проверкой SHA-256 либо оффлайн-импорт zip-архива для изолированных контуров.
  - Веса размещаются в системном каталоге данных пользователя (`platformdirs.user_data_dir("DOCXdodyr")`), а не в теле приложения.

### 2.2. Распознавание Apple Vision Framework (macOS)
- **Фреймворк**: `Vision.framework` (`VNRecognizeTextRequest`, Revision 2/3).
- **Правообладатель**: Apple Inc.
- **Тип лицензии**: Системный компонент macOS (System Framework).
- **Особенности**: Бинарные веса нейросети не извлекаются и не переупаковываются в проект. Приложение обращается к нативному API операционной системы через PyObjC. Использование разрешено лицензионным соглашением macOS (EULA Apple) на устройствах под управлением macOS 12.0+.

### 2.3. Tesseract OCR
- **Компоненты**: локальный исполняемый файл Tesseract и Python-обвязка `pytesseract`.
- **Лицензия обвязки**: **Apache License 2.0**.
- **Особенности**: приложение не скачивает движок или языковые данные автоматически; они должны быть установлены локально.

### 2.4. Лингвистический движок Pullenti (NER)
- **Библиотека**: `PullentiPython` (версия 0.1 / 4.1) и расширение `pullenti_legal`.
- **Правообладатель**: Константин Селезнев / Селезнева Т. В.
- **Лицензия**: Открытая лицензия (Free for non-commercial and commercial linguistic processing).
- **Особенности**: Включает встроенные грамматики и морфологические словари русского языка. Расширение `pullenti_legal` разработано в рамках DOCXдодыр и распространяется под открытой лицензией MIT.

## 3. Выводы и соответствие критериям релиза

1. Все используемые модели и алгоритмы имеют чистую лицензионную историю (Apache 2.0, MIT, System Framework) и не имеют несовместимых ограничений (отсутствуют лицензии категории «Non-Commercial Only» или «Research Only»).
2. Решение не включать веса Qwen в базовые бинарные сборки полностью устраняет риски раздувания дистрибутивов и соответствует политике компактного ядра.
3. Вся необходимая информация об авторах моделей отражена в `THIRD_PARTY_NOTICES.md`.
