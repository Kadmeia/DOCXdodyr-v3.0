# Структура проекта

| Путь | Назначение |
|---|---|
| `app/` | Основные модули обработки документов, обезличивания, восстановления и интерфейса |
| `web/` | Локальный интерфейс приложения |
| `assets/`, `resources/` | Иконки, манифесты и ресурсы для сборок |
| `scripts/`, `tools/` | Сборка, проверки и вспомогательные команды |
| `tests/` | Автоматические проверки и генераторы синтетических документов |
| `docs/` | Руководства и техническая документация |
| `requirements/`, `installer/` | Зависимости и установщик |
| `pullenti_legal/` | Отдельный Python-пакет юридического расширения |

В корне оставлены `main.py` (запуск приложения), `version.py`, `setup.py`,
модули системного контекстного меню и сценарии проверки упакованного приложения.
На них напрямую ссылаются команды запуска или сборка. `main.py` добавляет
`app/` в путь импорта; тесты используют настройку `pythonpath` в `pytest.ini`,
а PyInstaller — `pathex` в `DOCXdodyr.spec`.

Новые внутренние модули размещайте в `app/`. Тестовые документы создавайте
локально генераторами из `tests/`: они не входят в Git.
