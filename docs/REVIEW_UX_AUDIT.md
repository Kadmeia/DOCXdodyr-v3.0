# Аудит удобства ручной проверки

Проверен сценарий пользователя: открыть «Проверка найденных сущностей» → оставить безопасный фильтр «Ожидают проверки» → уточнить тип/документ/confidence → принять выборку или открыть карточку и принять/отклонить одну находку.

## Решения интерфейса

- По умолчанию видны только находки со статусом «Ожидает проверки»: завершённые решения не мешают первому проходу.
- Confidence вводится как понятный процент от 0 до 100; backend также принимает дробь 0..1 для интеграций.
- «Принять отфильтрованные» меняет только pending-находки текущей выборки. Уже принятые или отклонённые записи не перезаписываются.
- В карточке сначала показываются тип, confidence, документ и структурная позиция: абзац/колонтитул, ячейка листа или страница PDF.
- OCR-позиция отображается безопасной схемой страницы с прямоугольником bbox; исходное изображение и текст в preview не передаются.
- Escape закрывает модальное окно, фокус переводится внутрь окна, поля и кнопки имеют подписи для screen reader и живую строку результата.

## Автопроверка человекоподобного сценария

`tests/test_review_ux.py` проверяет фильтрацию без мутации очереди, массовое принятие, безопасный preview geometry, DOM-контракт фильтров, Escape, SVG bbox и запрет `innerHTML` для обезличенного контекста.
