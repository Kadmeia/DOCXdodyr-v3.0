# Диагностика проблем

DOCXдодыр v3.0.1.

| Симптом | Безопасные действия | Что приложить к обращению |
|---|---|---|
| Не запускается | Сверьте ОС/архитектуру и версию, проверьте целостность загрузки; используйте только проверенный дистрибутив | Версия, ОС, CPU и код ошибки без путей |
| Нет WebView2 | Установите официальный Microsoft WebView2 Runtime; повторите запуск под обычным пользователем | Наличие runtime и версия Windows |
| Gatekeeper/SmartScreen | macOS: правый клик (Control+клик) -> «Открыть», или `xattr -cr /Applications/DOCXdodyr.app`. Windows: нажмите «Подробнее» -> «Выполнить в любом случае» | Текст предупреждения без личных данных |
| OCR недоступен | Проверьте язык, разрешение и ориентацию синтетического скана, доступность Apple Vision/Tesseract | Результат capabilities и синтетический пример |
| Повреждённый/защищённый файл | Откройте собственную копию в исходном редакторе; снимите защиту только при наличии прав; сохраните исправленную копию | Формат и вид защиты, без пароля |
| Не хватает диска/памяти | Отмените операцию, дождитесь завершения, освободите место или уменьшите пакет; исходник сохраните | Размер/число страниц и свободное место |
| Нет модели | Базовая обработка работает без Qwen; установите модель с явным согласием или импортируйте offline bundle | Статус модели и целостности |
| Неверный дешифратор | Выберите JSON от того же комплекта; не редактируйте IDs/hashes, не принуждайте восстановление | Код проверки без значений JSON |
| Нет доступа к папке | Выберите доступную папку пользователя; не запускайте всё приложение администратором ради записи в install dir | Тип каталога, без полного пути |
| Сбой/зависшее продолжение | Сохраните исходники и рабочий комплект, перезапустите, проверьте checkpoint; не объединяйте вручную частичные результаты | Обезличенный статус recovery |

В меню «Помощь» доступна локальная справка и безопасная диагностика. Разработчик может вызвать `--diagnostics --report-file <новый файл>`: отчёт предназначен для проверки перед передачей. Не прикладывайте исходные документы, дешифраторы, скриншоты с данными, дампы, vault и пользовательские списки. Для первого запуска сборок без платных сертификатов используйте штатные средства подтверждения доверия операционной системы.
