# ADR 0005: Каналы распространения публичных релизов

## Статус
Принято (Accepted) — 2026-09-03

## Контекст
При подготовке публичного релиза требовалось определить канал дистрибуции бинарных сборок DOCXдодыр для macOS и Windows. Рассматривались централизованные магазины (Mac App Store, Microsoft Store), прямая дистрибуция через GitHub Releases и собственный веб-сайт.

## Решение
1. Принять **GitHub Releases** в качестве основного официального канала распространения релизных сборок DOCXдодыр.
2. Для каждого публичного релиза автоматически и воспроизводимо формируются следующие артефакты:
   - `DOCXdodyr-<version>-macOS-arm64.dmg` (для Apple Silicon M1/M2/M3/M4);
   - `DOCXdodyr-<version>-macOS-x86_64.dmg` (для Intel Mac);
   - `DOCXdodyr-Setup-<version>-win64.exe` (установщик Inno Setup для Windows x64);
   - `SHA256SUMS.txt` (манифест контрольных сумм всех файлов);
   - `RELEASE_NOTES.md` (список изменений и улучшений);
   - Лицензионные уведомления (`EULA.txt`, `THIRD_PARTY_NOTICES.md`).
3. Отказаться от публикации в Mac App Store и Microsoft Store для версии 2.2:
   - Требование App Sandbox блокирует прозрачную работу с произвольными папками на внешних и сетевых дисках;
   - Запрет на использование сторонних утилит и ограничение межпроцессного взаимодействия создаёт избыточные сложности для desktop-утилит обработки документов.

## Последствия
- Положительные: быстрая доставка обновлений; полная свобода работы с файловой системой пользователя; отсутствие задержек модерации магазинов; прозрачность сборки через GitHub.
- Ограничения: необходимость явных инструкций для пользователей по обходу Gatekeeper / SmartScreen в случае отсутствия платных сертификатов подписи.
