# ADR 0001: Выбор модели лицензирования продукта

## Статус
Принято (Accepted) — 2026-09-03

## Контекст
Проект DOCXдодыр готовится к первому публичному production-релизу на платформах macOS и Windows.
В репозитории присутствовали противоречия в метаданных:
- `README.md` указывал статус `Proprietary. Все права защищены.`
- `pyproject.toml` для отдельного картриджа `docxdodyr-pullenti-legal` указывал `MIT License`.
- В корне проекта отсутствовали файлы `LICENSE`, `EULA`, `PRIVACY_POLICY.md` и `THIRD_PARTY_NOTICES.md`.
Требовалось зафиксировать правовую модель для бинарных сборок приложения и исходного кода.

## Решение
1. Принять для десктопного приложения DOCXдодыр модель **Freeware** (бесплатное проприетарное ПО под лицензионным соглашением EULA).
2. Бинарные дистрибутивы (.app/DMG для macOS, Installer для Windows) распространяются для пользователей бесплатно без взимания платы за скачивание или базовую эксплуатацию.
3. Права на товарный знак, бренд, оформление интерфейса и исходный код ядра защищаются от несанкционированной перепродажи, переупаковки или коммерческого закрытия третьими лицами без согласия правообладателя.
4. Лингвистический картридж юридических правил `pullenti_legal` оформляется и распространяется отдельно под открытой лицензией MIT.
5. В поставку дистрибутива включаются обязательные документы: `EULA.txt`, `PRIVACY_POLICY.md` и `THIRD_PARTY_NOTICES.md` с перечислением всех open-source компонентов (PyWebView, Pullenti, PyMuPDF, openpyxl, pdfplumber и др.).

## Последствия
- Положительные: ясность прав для конечных пользователей; бесплатная доступность инструмента для юристов и бухгалтеров; защита от недобросовестного присвоения и перепродажи инструмента.
- Ограничения: на этапе 03 потребуется подготовить тексты EULA и сторонних лицензионных уведомлений; запрещено декларировать приложение в корне как open-source без оговорки о разделении ядра/картриджа.
