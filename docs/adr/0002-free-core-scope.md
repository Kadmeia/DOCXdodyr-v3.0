# ADR 0002: Состав бесплатного ядра публичной версии

## Статус
Принято (Accepted) — 2026-09-03

## Контекст
При подготовке публичного релиза DOCXдодыр требовалось определить границу возможностей бесплатной редакции: сохранять ли полный доступ ко всем функциям или ввести искусственные лимиты (Freemium / Pro) на объём документов, пакетный режим или специфические форматы.

## Решение
1. Бесплатное ядро публичной версии DOCXдодыр 2.2 включает **весь спектр локальных функций без искусственных ограничений**:
   - Одиночная и пакетная обработка файлов DOCX, XLSX, текстовых и сканированных PDF;
   - Распознавание текста скан-документов через локальный OCR (Apple Vision / Tesseract);
   - Формирование локального дешифратора (`дешифратор.json`) и полное обратное восстановление документов;
   - Необратимая растеризация PDF без текстового слоя;
   - Аудит и удаление скрытых данных (метаданные, примечания, авторы, ревизии);
   - Ручная интерактивная проверка сущностей (Review queue);
   - Настройка списков исключений и правил принудительных замен;
   - Рекурсивная пакетная обработка папок с контролем целостности.
2. Не вводить водяные знаки, ограничения по количеству страниц, тайм-ауты или триальные периоды.
3. Монетизация и поддержка проекта осуществляются исключительно через добровольные пожертвования (донаты) с переходом из окна «Поддержать автора».

## Последствия
- Положительные: отсутствие необходимости встраивать сложные механизмы лицензирования, ключей активации и анти-пиратской защиты в релиз 2.2; максимальное доверие целевой аудитории (юристы, адвокаты, корпоративные пользователи).
- Ограничения: вся кодовая база релиза 2.2 остаётся единым монолитным пакетом без разветвления на Free/Pro сборки.
