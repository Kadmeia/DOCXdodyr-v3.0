# ADR 0004: Поддерживаемые платформы и минимальные версии операционных систем

## Статус
Принято (Accepted) — 2026-09-03. Требование к macOS актуализировано для версии 3.0; дата принятия не является датой нативной проверки.

## Контекст
Для сборки production-пакетов (.app, DMG, Windows Installer) необходимо чётко зафиксировать минимальные требования к версиям операционных систем и аппаратным архитектурам. Приложение использует PyWebView (WKWebView на macOS, WebView2 на Windows), системные вызовы OCR (Apple Vision API) и зависимости Python 3.11.x.

## Решение
1. **macOS**:
   - Минимальная версия ОС: **macOS 14.0 (Sonoma)**.
   - Поддерживаемые аппаратные архитектуры: **Apple Silicon (`arm64`)** и **Intel (`x86_64`)**.
   - Обоснование: минимальная версия согласована с текущими настройками сборки и упаковки; совместимость всех включённых бинарных библиотек должна проверяться по deployment target и нативным запуском. OCR использует Apple Vision Framework (`VNRecognizeTextRequest`). На macOS используется системный WKWebView, не требующий внешних браузерных рантаймов. Сборка формируется в виде `.app` внутри DMG-образа.
2. **Windows**:
   - Минимальная версия ОС: **Windows 10 (версия 1809+, 64-бит)** и **Windows 11 (64-бит)**.
   - Поддерживаемая аппаратная архитектура: **`x86_64` (amd64)**. Поддержка 32-битных версий (x86) и устаревших ОС (Windows 7/8/8.1) не осуществляется.
   - Обоснование: стандартный Microsoft Edge WebView2 Evergreen Runtime предустановлен в Windows 11 и современных сборках Windows 10. Сборка формируется как per-user установщик (Inno Setup).

## Последствия
- Положительные: единая минимальная версия ОС для документации, сборочных скриптов и метаданных приложения.
- Ограничения: на этапе 06 необходимо тестировать установленные сборки на macOS 14+ на arm64 и x86_64; development-сборка на macOS 26.2 не подтверждает работу на macOS 14; на этапе 07 установщик Windows должен проверять наличие WebView2 и предлагать установку при его отсутствии.
