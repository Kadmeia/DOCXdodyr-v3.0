## 📌 О проекте

**DOCXдодыр** — это локальный инструмент для юристов, бухгалтеров, кадровиков, аналитиков и специалистов по информационной безопасности. Приложение предназначено для автоматического и полуавтоматического удаления персональных данных (ПДн) и конфиденциальных реквизитов из документов перед их отправкой клиентам, контрагентам, в суд, публикацией в открытых источниках или передачей в сторонние нейросети и облачные сервисы.

Программа выявляет чувствительные данные в тексте и заменяет их на читаемые плейсхолдеры (например, `[ФИО]`, `[СерияПаспорта]`, `[НомерПаспорта]`, `[Адрес]`, `[ИНН]`), полностью вычищает скрытые метаданные и формирует зашифрованный файл-дешифратор, позволяющий при необходимости восстановить исходный документ в первоначальном виде.

### 🛡️ Главный принцип: 100% Local-First (Полная автономность)

- **Никаких облачных серверов:** Все операции парсинга, поиска сущностей, оптического распознавания и модификации файлов происходят строго на вашем локальном компьютере.
- **Безопасность для конфиденциальных данных:** Подходит для работы с документами, подпадающими под действие 152-ФЗ «О персональных данных», содержащими коммерческую, служебную или адвокатскую тайну.
- **Работа без интернета:** Программа полностью автономна и готова к работе на изолированных рабочих станциях (в закрытом контуре / Air-Gapped).

## ✨ Ключевые возможности

- 📄 **Широкая поддержка форматов**:
  - **DOCX (Microsoft Word):** замена в параграфах, таблицах любой сложности, сносках, колонтитулах и графических текстовых блоках с сохранением оригинального форматирования.
  - **XLSX (Microsoft Excel):** построчная обработка ячеек таблиц с сохранением структуры книги, листов и формул.
  - **PDF и сканы:** обработка цифровых векторных PDF, а также растровых сканов и изображений.

- 🔍 **Глубокий NER-анализ (Pullenti + контекстные правила)**:
  - Специализированный картридж юридических правил на базе **Pullenti** для текстов правовой и деловой сферы РФ.
  - Распознавание ФИО во всех падежных формах, паспортов РФ (серия, номер, дата и орган выдачи, код подразделения), СНИЛС, ИНН (физических и юридических лиц), ОГРН/ОГРНИП, адресов, банковских реквизитов (р/с, к/с, БИК), контактов (телефоны, email), номеров судебных дел, дат и денежных сумм.
  - Контекстный анализ: интеллектуальный фильтр отличает персональные реквизиты сторон от названий законов, статей кодексов, госорганов и общеупотребимой лексики.

- 👁️ **Встроенный модуль OCR (оптическое распознавание)**:
  - **macOS:** аппаратное распознавание через нативный системный фреймворк Apple Vision — высокая скорость и точность без установки внешних библиотек.
  - **Windows / Fallback:** интеграция с движком Tesseract OCR.

- 🔐 **Обратимость и шифрование (Дешифратор)**:
  - Формирование файла соответствий `дешифратор.json` для точного обратного восстановления исходного документа.
  - Защита сессионных данных и ключей: шифрование алгоритмом Fernet (AES-128-CBC с HMAC) с интеграцией в системный диспетчер учетных данных (Keychain на macOS, Credential Manager на Windows).

- 🧹 **Очистка скрытых данных (Privacy Audit)**:
  - Обнаружение и удаление комментариев, примечаний, скрытого текста, истории изменений (Track Changes).
  - Очистка метаданных документов (автор, организация, даты редактирования, история правок, пути шаблонов) и интерактивных форм (AcroForms).

- 🧑‍💻 **Интерактивная верификация (Human-in-the-Loop)**:
  - Наглядный интерфейс ручной проверки с возможностью подтвердить, скорректировать или исключить любую найденную сущность перед финальным сохранением.

- 🤖 **Опциональная локальная нейросеть (Qwen LLM)**:
  - Возможность подключения компактной оффлайн-модели Qwen для сложного контекстного анализа и нестандартных документов без отправки данных в сеть.

## 🚀 Быстрый старт

### Способ 1. Запуск в один клик (для пользователей)

Не требует ручной настройки окружения и работы в терминале:

- **Windows**: Дважды кликните по файлу `run_windows.bat` в папке программы. Скрипт создаст изолированное окружение `venv`, установит необходимые зависимости и запустит графический интерфейс.
- **macOS**: Дважды кликните по файлу `run_macos.command` в Finder.

### Способ 2. Запуск из исходного кода (для разработчиков)

Рекомендуется использовать **Python 3.11.x**:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/aebeloglazov/DOCXdodyr.git
   cd DOCXdodyr
   ```

2. Создайте и активируйте виртуальное окружение:
   - **macOS / Linux:**
     ```bash
     python3.11 -m venv venv
     source venv/bin/activate
     ```
   - **Windows (PowerShell):**
     ```powershell
     py -3.11 -m venv venv
     .\venv\Scripts\Activate.ps1
     ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```bash
   python main.py
   ```

## 📁 Структура проекта

```
DOCXdodyr/
├── app/                  # Ядро приложения: NER-движок, замена данных, OCR, восстановление
│   ├── backend_api.py    # Главный API для графического интерфейса
│   ├── detection_engine.py # Правила и регулярные выражения поиска ПДн
│   ├── legal_pullenti.py # Интеграция с Pullenti для юридических документов
│   ├── placeholders.py   # Генерация плейсхолдеров и таблицы соответствий
│   ├── document_restorer.py # Модуль восстановления оригиналов по дешифратору
│   ├── hidden_data.py    # Анализ и удаление скрытых данных и метаданных
│   └── ocr_backend.py    # Оптическое распознавание (Apple Vision / Tesseract)
├── web/                  # Графический интерфейс (HTML, CSS, JavaScript)
├── pullenti_legal/       # Картридж юридических правил для Pullenti
├── docs/                 # Документация пользователя и разработчика
├── tests/                # Набор модульных и интеграционных тестов
├── main.py               # Точка входа в приложение (pywebview GUI)
├── run_windows.bat       # Скрипт запуска в 1 клик для Windows
├── run_macos.command     # Скрипт запуска в 1 клик для macOS
└── version.py            # Единый источник версии (v3.0.2)
```

Подробное описание модулей доступно в файле [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md).
