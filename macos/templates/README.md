# DOCXdodyr Quick Action templates

Automator `document.wflow` property lists are generated by
`macos_context_menu.materialize_quick_actions()`. They intentionally contain
only a trusted frozen-app path and use `"$@"` for Finder arguments. The
workflow invokes the bundled executable directly; it does not depend on a
system `/usr/bin/python3`.

Do not replace this boundary with string interpolation, `eval`, or an
unquoted `$1`/`$@` expansion.
