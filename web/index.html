Вы действительно хотите установить Qwen 3.5 0.8B?

Модель работает полностью локально на вашем устройстве без обращения к внешним серверам и интернету. Она автоматически согласовывает падежи, окончания и связность фраз при подстановке исходных данных из дешифратора.

Пример использования:
Без Qwen: «...выдано представителю Иванов Иван Иванович»
С Qwen 3.5: «...выдано представителю Иванову Ивану Ивановичу»
Объем загрузки: ~1.75 ГБ. Загружается один раз в каталог пользователя.

Локальная обработка документов

Готово к работе

Нажмите для выбора файлов или перетащите их сюда

Поддерживаемые форматы: .docx, .xlsx, .pdf, .jpg, .png, .tiff, .bmp, .webp

Обезличить папку целиком

Перетащите сюда папку или выберите её кнопкой. Все документы (DOCX, XLSX, PDF, сканы и фото) будут обработаны. Результаты попадут в подпапку «Обезличенные документы», исходные файлы не изменяются.

Папка не выбрана

Общий JSON-дешифратор сохраняется в выбранной папке, чтобы его можно было найти из вложенных документов.

Форматы сохранения

Готово

Если ни один формат не выбран, сохраняется исходный формат (DOCX→DOCX, XLSX→XLSX, PDF→PDF, фото→PDF). При выборе форматов создаются только выбранные.
